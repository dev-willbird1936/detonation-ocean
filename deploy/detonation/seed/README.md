# Detonation seed profile

`home/dana/` is the synthetic home directory seeded into each job's `do-<jobId>-home` volume (SPEC section 6.2). Every value is fake.

## Canary placeholder

Honey files contain `{{CANARY}}`. The controller replaces each occurrence with a unique per-job token before the volume is seeded.

- The token is exactly 10 characters from `A-Z0-9`. Equal lengths let the controller rewrite files byte for byte, including the SQLite files, without changing their structure.
- In `.aws/credentials`, `AKIA{{CANARY}}FAKE00` becomes a 20-character AKIA-shaped key.
- The controller records the seed manifest (path, size, SHA-256) after substitution.

## Files

- Text files are committed directly: notes, photo list, to-do list, `.aws/credentials`, `.ssh/id_ed25519`, `.env`, and the Electrum wallet.
- Binary files are generated by `python tools/make-seed.py`: `Q3-report.docx`, `budget.xlsx`, two PNGs in `Pictures/`, and the Chromium `Login Data` and `Cookies` SQLite files.
- `Downloads/` holds only `.keep`; the job copies its upload there.
