# Creature depth evolution study

Open `index.html` directly in Chrome. It shows six creature families with three palette-indexed sprite forms each:

| Form | Ocean depths |
|---|---|
| Shared base | Sunlight, Twilight |
| Mid-depth evolution | Midnight, Abyss |
| Advanced form | Trench |

The gallery uses the exact RGB role profiles from `palette-profiles.json`. It distinguishes local palette-indexed exports from unmodified native sources; click **Native source** to open the original PNG.

## Current preview state

The gallery shows the **18 normalized morphology sources** from `depth-colors/morphology/` (six families × Base, Mid, Trench), each in its Sunlight palette, as 256 px PNG with a 128 px download. They are candidates accepted for the colour pipeline, not final art. The sixth line is **Squid → Kraken** and uses Squid sources only; no Octopus asset is used. The 30 depth-coloured variants live in the separate 6×5 grid (`../codex-creature-palette-base/index.html`). This page is the three-form study only; it has no animation. The live desktop and mobile captures linked from `../../docs/evidence/ocean-evolution-gallery-live-verification.json` predate this normalization and are historical.

## Provenance

- The six base morphologies come from `../codex-creature-palette-base/`. `variants/*-base-rich-*` are offline role-mask recolors with stepped shadow/base/highlight shades. Original base PNGs and three role masks remain unchanged.
- Twelve new stills were generated by Codex native `image_gen.imagegen`: one Midnight/Abyss and one Trench morphology per family. `generation-report.json` records each full prompt, reference hashes, native staging path, copy hash, dimensions and alpha channel. Local PNG copies remain byte-identical to native staging.
- `variants/` holds 128px game exports and nearest-neighbor 256px displays quantized to each family's nine role colors plus neutral details. `masks/` stores three semantic masks and shade masks for each of the 18 final cells. No new anatomy was drawn locally.
- `reference-manifest.json` retains the two immutable prompt inputs per family. `packaging-recovery.json` records 162 zero-pixel masks from an earlier failed packaging attempt; they were hash-checked, preserved under `masks/recovery-empty-v1/`, and are not referenced by the final manifest.

## Evidence and checks

- `variant-manifest.json` maps all 18 forms to families, grouped depths, native/base inputs, profile colors, file hashes, mask paths and visible-pixel counts. `integrity-verification-recheck.json` rechecked the native hashes, all variant exports, palette values, 216 role/shade masks, preserved recovery files, the 12 generation reports, and the separate 30 style/depth outputs. `integrity-verification.json` preserves the earlier failed verifier attempt; its duplicate-reference-root path bug was corrected in the recheck.
- `depth-evolution-contact-sheet.png` shows the full six-family by three-form comparison. `visual-review.json` records the parent review of all 12 native images, including the isopod anatomy and octopus stage-difference caveats.
- `browser-verification.json`, `browser-verification-final.json`, and `browser-verification-layout-fix.json` preserve checks of the prior Octopus-based view, including its corrected 18-card layout. The current Squid-line gallery has a separate independent full-page desktop and mobile capture plus HTTP/image checks in `../../docs/evidence/ocean-evolution-gallery-live-verification.json`. Earlier captures remain historical and are not used as evidence for the current Squid line.
- Codex generation cost and quota were not reported. No purchases, subscriptions, RetroDiffusion requests or other providers were used.

This is an additive art prototype. It does not modify the main app, ocean backgrounds, or the separate six-style/five-depth composition viewer. It is a visual concept study, not scientific species validation, animation, or 3D.
